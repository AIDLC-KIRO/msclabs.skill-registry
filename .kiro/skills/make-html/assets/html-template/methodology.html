About AWS Transform (ATX)เกี่ยวกับ AWS Transform (ATX)

AWS Transform (ATX) is an AWS-managed, agent-driven analysis toolchain. Each transformation performs deep static analysis of a repository and produces hierarchical, cross-referenced documentation. This assessment was run with the ATX CLI ({{METHOD_ATX_CLI_VERSION}}) against the {{APP_NAME}} repository in a clean Git state. Every finding is evidence-based and cites source files — the agent is instructed not to invent detail.AWS Transform (ATX) คือชุดเครื่องมือวิเคราะห์ที่ขับเคลื่อนด้วย agent และบริหารจัดการโดย AWS แต่ละ transformation จะทำการวิเคราะห์โค้ดเชิงสถิต (static analysis) เชิงลึกและสร้างเอกสารแบบลำดับชั้นที่อ้างอิงข้ามกันได้ การประเมินนี้รันด้วย ATX CLI ({{METHOD_ATX_CLI_VERSION}}) กับ repository ของ {{APP_NAME}} ในสถานะ Git ที่สะอาด ทุกผลการวิเคราะห์อ้างอิงจากหลักฐานจริงและระบุไฟล์ต้นทาง — โดย agent ถูกกำหนดไม่ให้สร้างข้อมูลขึ้นเอง

# Background run with logging

# Name + path form (enables version pinning with --tv)
atx custom def exec -p {{METHOD_REPO_PATH}} \
  -n AWS/modernization-readiness-analysis -c "noop" -x -t

Reproducibility note: --tv <version> pins a transformation version but only works with the -n (name) form, not with -g (config file). Prerequisites: ATX CLI {{METHOD_ATX_CLI_VERSION}} with transform-custom:* permissions, configured AWS credentials, and a clean Git state.หมายเหตุการทำซ้ำ: --tv <version> ใช้ตรึงเวอร์ชันของ transformation แต่ทำงานได้เฉพาะกับรูปแบบ -n (ชื่อ) ไม่ใช่ -g (ไฟล์ config) ข้อกำหนดเบื้องต้น: ATX CLI {{METHOD_ATX_CLI_VERSION}} ที่มีสิทธิ์ transform-custom:*, ตั้งค่า AWS credentials แล้ว และ repository อยู่ในสถานะ Git ที่สะอาด
