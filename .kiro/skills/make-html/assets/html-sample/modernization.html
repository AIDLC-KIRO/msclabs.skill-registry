Pattern Recommendationsคำแนะนำรูปแบบ (Patterns)

Anti-corruption Layer

Wrap the TrakCare REST contract behind an adapter so the new services never depend on its field names or the empty-string conventions the current code relies on.ห่อสัญญา REST ของ TrakCare ไว้หลัง adapter เพื่อให้เซอร์วิสใหม่ไม่ต้องผูกกับชื่อฟิลด์หรือธรรมเนียมการใช้สตริงว่างที่โค้ดปัจจุบันพึ่งพา

Saga Pattern

Replace the multi-step temp-table staging transaction with a saga so appointment sync can compensate cleanly when a step fails midway.แทนที่ธุรกรรมหลายขั้นตอนที่ใช้ตารางชั่วคราวด้วยรูปแบบ saga เพื่อให้การซิงก์นัดหมายย้อนกลับได้อย่างสะอาดเมื่อขั้นตอนใดล้มเหลวกลางทาง

Event Sourcing

The room login/logout and patient status flows are already event-shaped; persisting those events gives an audit trail the current schema cannot provide.กระแสการเข้าออกห้องตรวจและสถานะผู้ป่วยมีลักษณะเป็นเหตุการณ์อยู่แล้ว การจัดเก็บเหตุการณ์เหล่านั้นจะให้ร่องรอยการตรวจสอบที่สคีมาปัจจุบันทำไม่ได้

Hexagonal Architecture

Separate the SQL and TrakCare adapters from business rules so the status-mapping CASE and the 10-minute alert logic become testable in isolation.แยก adapter ของ SQL และ TrakCare ออกจากกฎทางธุรกิจ เพื่อให้ CASE ที่แปลงสถานะและตรรกะแจ้งเตือน 10 นาทีทดสอบแยกส่วนได้
