About AWS Transform (ATX)เกี่ยวกับ AWS Transform (ATX)

AWS Transform (ATX) is an AWS-managed, agent-driven analysis toolchain. Each transformation performs deep static analysis of a repository and produces hierarchical, cross-referenced documentation. This assessment was run with the ATX CLI (v3.4.0+) against the Dental Dashboard repository in a clean Git state. Every finding is evidence-based and cites source files — the agent is instructed not to invent detail.AWS Transform (ATX) คือชุดเครื่องมือวิเคราะห์ที่ขับเคลื่อนด้วย agent และบริหารจัดการโดย AWS แต่ละ transformation จะทำการวิเคราะห์โค้ดเชิงสถิต (static analysis) เชิงลึกและสร้างเอกสารแบบลำดับชั้นที่อ้างอิงข้ามกันได้ การประเมินนี้รันด้วย ATX CLI (v3.4.0+) กับ repository ของ Dental Dashboard ในสถานะ Git ที่สะอาด ทุกผลการวิเคราะห์อ้างอิงจากหลักฐานจริงและระบุไฟล์ต้นทาง — โดย agent ถูกกำหนดไม่ให้สร้างข้อมูลขึ้นเอง

Reproducible Configurationการตั้งค่าที่ทำซ้ำได้

The additionalPlanContext value has a hard 4,096-character API limit (rich guidance lives in file comments, which are not counted).การรันแต่ละครั้งขับเคลื่อนด้วยไฟล์ config ที่อยู่ใน version control โดยรองรับคีย์เพียงสี่ตัวเท่านั้น ค่า additionalPlanContext มีขีดจำกัด API ที่ 4,096 ตัวอักษร (คำแนะนำเชิงลึกอยู่ในคอมเมนต์ของไฟล์ซึ่งไม่ถูกนับรวม)

# Background run with logging
